# Wooseong Yang — Academic Website

Personal academic website for Wooseong Yang, hosted with GitHub Pages.

The site is intentionally build-free: edit the HTML/CSS files and push to the `main` branch.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Content sources

- Publication metadata: Wooseong Yang's Google Scholar profile
- Profile image: public Google Scholar profile asset
- Go-RIO figure: the public `wooseongY/Go-RIO` repository
- MOANA preview: the public MOANA project publication image
